# Generated table folder

This folder is used to store the tables generated by the associated visualisation pipeline
[`step_6_visualization.2.py`](https://github.com/BGI-SynBio/SPIDER-WEB/tree/main/works/step_6_visualization.2.py).
The underlying data used to generate these tables are provided in the package data folder 
[`pkg`](https://github.com/BGI-SynBio/SPIDER-WEB/tree/main/works/pkg).

Please note that Tab. S4 was not generated from this pipeline. 
The relevant data are derived from Tables 1 and 2 of the 
[AWS HPC Blog](https://aws.amazon.com/cn/blogs/hpc/benchmarking-the-oxford-nanopore-technologies-basecallers-on-aws/)
(named Benchmarking the Oxford Nanopore Technologies basecallers on AWS), 
systematically obtained by Stefan Dittforth, Doruk Ozturk, and Michael Mueller.
Accordingly, these data were manually transcribed into the LaTeX document.
