# Experiment 1 data folder

This folder stores high-throughput sequencing data associated with the experiments designed 
to compare the conventional data retrieval pipeline and the SPIDER-WEB retrieval pipeline.

In total, this folder includes 18 pairs of PE-150 paired-end sequencing reads file. 
These sequencing reads are parsed and processed by 
[`step_3_experiments.py`](https://github.com/BGI-SynBio/SPIDER-WEB/blob/main/works/step_3_experiments.py#L50), 
and the resulting analyses support the experimental results shown in Fig. 3 and Fig. 4.
