# Experimental data folder

Some of the data were obtained from wet-lab experiments and are provided here 
as experimental raw data for reproducing or inspecting the corresponding analyses.

This folder contains three subfolders, each corresponding to one set of experimental results:
- [`1`](https://github.com/BGI-SynBio/SPIDER-WEB/tree/main/works/exp/1): high-throughput sequencing data associated with the experiments shown in Fig. 3 and Fig. 4.
- [`2`](https://github.com/BGI-SynBio/SPIDER-WEB/tree/main/works/exp/2): high-throughput sequencing data associated with the experiments shown in Fig. 6c-e.
- [`3`](https://github.com/BGI-SynBio/SPIDER-WEB/tree/main/works/exp/3): single-molecule nanopore sequencing data and its corresponding rendering data associated with the experiments shown in Fig. 6f.

These experimental data are separated from the intermediate computational raw data 
because they serve as external experimental inputs rather than outputs generated by the pipeline scripts.
