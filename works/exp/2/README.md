# Experiment 2 data folder

This folder contains high-throughput sequencing data associated with the experiments 
used to evaluate the baseline error profiles of the 160 sequence samples
before the real-time data retrieval experiments.

The files are parsed and processed by 
[step_4_supplements.py](https://github.com/BGI-SynBio/SPIDER-WEB/blob/main/works/step_4_supplements.py#L442), 
and the resulting analyses support the results shown in Fig. 6c-e.
