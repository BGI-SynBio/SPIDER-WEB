# Generated figure folder

This folder is used to store the figures generated by the associated visualisation pipelines 
[`step_6_visualization.1.py`](https://github.com/BGI-SynBio/SPIDER-WEB/tree/main/works/step_6_visualization.1.py) and 
[`step_6_visualization.2.py`](https://github.com/BGI-SynBio/SPIDER-WEB/tree/main/works/step_6_visualization.2.py).
The underlying data used to generate these figures are provided in the package data folder 
[`pkg`](https://github.com/BGI-SynBio/SPIDER-WEB/tree/main/works/pkg).

Please note that Fig. 1a, which is detailed in main-01.pdf, was not generated from these pipelines. 
Instead, it was created using BioRender and further assembled with Adobe Illustrator. 
Therefore, the generated figure outputs in this folder do not include the components corresponding to Fig. 1a.
