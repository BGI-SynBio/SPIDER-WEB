# Packaged data folder

This folder stores the packaged data files used for visualisation. 
These files were derived from the corresponding files 
in the [`raw`](https://github.com/BGI-SynBio/SPIDER-WEB/tree/main/works/raw) folder 
and were prepared to support figure generation by the associated visualisation pipelines.

The packaging pipelines include 
[`step_5_packaging.1.py`](https://github.com/BGI-SynBio/SPIDER-WEB/tree/main/works/step_5_packaging.1.py) and 
[`step_5_packaging.2.py`](https://github.com/BGI-SynBio/SPIDER-WEB/tree/main/works/step_5_packaging.2.py).

The information for the six figures included in the main text, as well as 
the twenty figures and three tables included in the Supplementary Information is summarised below.
For access to any of the following files, please contact 
the [authors](https://github.com/BGI-SynBio/SPIDER-WEB/blob/main/CORRESPONDENCE.md).
